# 基础图片工具箱：第一批

入口为 `/app/toolbox`，用户侧栏显示「图片工具箱」。原有图片编辑器继续提供 AI 处理、选区修边和矩形 / 圆形裁切；切换编辑器工具时，效果图预览底色恢复透明。

## 已支持的处理

- 压缩：PNG 无损优化；JPG / WebP 可指定质量或目标 KB。目标大小模式寻找满足大小限制的较高编码质量，不会偷偷缩小尺寸；最低质量仍无法达标时，任务明确失败。
- 格式：PNG、JPG、WebP。PNG / WebP 保留透明通道，JPG 根据填充颜色合成不透明图片。
- 尺寸：自定义宽高、常用尺寸预设、等比适应、居中铺满裁切、拉伸和百分比缩放。
- 方向与画布：顺时针 90° / 180° / 270°、水平 / 垂直翻转、自动去除透明外边、四周留白。
- 背景合成：保持透明、纯色底、背景图片。背景会写入导出文件；已有不透明背景的图片需先抠图。
- 批量：上传多张或从素材库跨页多选、统一参数、批次名与文件名前缀、逐图状态、单图重试 / 取消排队、单张原格式下载、成功结果 ZIP 打包。

各工具的设置可组合使用。实际处理顺序固定为：去透明边 → 缩放 / 居中裁切 → 旋转 → 翻转 → 留白 / 背景合成 → 编码。

预览使用独立浏览器 Worker，最长边降采样到 1000 像素，用于检查布局。透明裁边预览使用降采样估计，最终裁边和编码在后端处理原始像素。界面明确区分布局预览与正式结果。

## 队列与素材

新增操作 `image.toolbox`，复用现有 `image-jobs` 队列、会员并发限制、积分账本、失败退款和任务中心。每张图一个任务，整批提交在同一个数据库事务中完成；积分不足或来源失效时整批回滚。

接口：

- `POST /api/v1/toolbox/quote`：为已选素材生成共享批次的逐图报价。
- `POST /api/v1/toolbox/submit`：提交报价，使用报价 ID 保证重复请求不重复创建任务 / 扣费。
- `GET /api/v1/jobs?operation_code=image.toolbox&batch_id=...`：读取批次任务。
- `POST /api/v1/assets/download-bundle`：验证所有素材归属后打包。

提交先保存数据库记录再返回，队列通知在响应后执行。现有调度器负责补投未送达任务。提交完成即可继续其他操作，已提交任务不依赖页面是否打开。前端在提交结果不明时保留原报价，并支持刷新页面后重试确认。

每个输出是原素材的新版本，不覆盖原图；保存压缩后的真实字节、扩展名、MIME、大小和 SHA-256，避免被通用素材归一化重新转成 PNG。批次按每张图片的最新尝试展示，跨页读取重试记录，避免打包时漏掉较早完成的图片。

## 限制与启用

每批最多 50 张静态 PNG / JPG / WebP；工具箱输入 / 输出最长边 12000 像素、总像素最多 1600 万，输出同时受会员像素额度限制；ZIP 单次最大 256 MiB。PNG 不提供有损目标 KB 压缩。默认尺寸设置为 2000 × 2000，保持原尺寸时不会自动放大。

数据库升级到 `20260913_0016` 后注册操作，初始单价为 0 积分，可通过现有后台定价调整。正常部署流程的 `migrate` 服务应先完成升级，再启动更新后的 Web / Worker。此次仅修改代码，未部署线上环境。
