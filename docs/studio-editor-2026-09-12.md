# 图片编辑器交互更新

- 所有工具共用紧凑设置面板、预览底色和提交区。短参数采用同行布局，长说明放在支持悬停、键盘聚焦和点击的提示图标中。印花提取继续保留透明/不透明和 2048～3072 像素输出尺寸。
- 移除画布底部“本次任务”列表，后台任务仍独立轮询、更新余额；修改草稿或切换工具后，旧任务完成不会覆盖当前编辑内容。任务中心继续提供完整任务记录，并发和排队规则沿用后端配置。
- 原图始终采用中性棋盘格。自定义颜色、白/深色和本地背景图片只影响右侧效果预览，不参与任务参数或导出。选区修边中也只有右侧跟随预览底色。
- 修边按钮在悬停/聚焦时预取图层，同一编辑器共享正在进行的请求；只保留最近一张的短期内存缓存，离开编辑器释放。去底前原图的图片字节到达后即可显示，不再等待结果下载及完整选区计算。编辑和导出继续使用原尺寸像素。
- 画布新增矩形/圆形裁切，支持拖动、右下角缩放、方向键移动和像素数值输入，实时展示裁切效果。保存产生独立 PNG 版本，不扣积分，随后可以继续处理或下载；生成工具会使用裁切后的图作为参考图。
- 新接口 `POST /api/v1/assets/{asset_id}/crop` 接受 `x/y/width/height/shape`，限制素材归属、可用状态、整数坐标、边界和像素数（不超过会员/系统限制及 1600 万像素）。圆形要求宽高相同，外侧透明，保留图案已有透明度。原图和恢复图层按相同区域裁切，防止后续修边恢复圆外内容；保留原素材及完整版本关系。

## 验证

裁切像素、EXIF 方向、圆形透明边缘、恢复图层、素材归属、删除状态、积分不变及非法输入均有后端测试。前端覆盖裁切拖动/尺寸/保存失败重试、后续任务使用裁切版本、修边原图提前展示和预取复用、预览背景隔离及连续提交。

本地前端 104 项测试通过。后端 314 项非外部集成测试均已验证：全量运行 313 项通过，一项 ONNX DLL 加载被沙箱拒绝；该文件的两项测试在沙箱外复核通过。质量范围覆盖率 83.92%，核心覆盖率 97.61%。Ruff、Mypy、TypeScript 检查及生产构建通过。

浏览器检查使用本地模拟账户和素材接口、真实前端与修边 Worker：1280×720 下十二个工具的导航及常用设置可显示，印花提取与电商页提交按钮完整可见；390px 下设置、说明和圆形裁切无横向溢出。未调用真实收费图片服务，未部署到服务器；此更新不新增数据库迁移。
