# 图片任务与编辑器更新

当前更新包含数据库迁移 `20260910_0012`，必须运行 migrate 后再启动新版 Web、Worker 和 Scheduler。前端已包含在应用镜像内。

## 9 月 10 日新增功能

- **注册**：超级管理员进入“系统配置 → 通用设置”，可直接切换“开放用户注册”并保存生效。开启后登录页提供“创建账号”，也可访问 `/register`。后端每次注册读取当前生效开关，关闭后拒绝新注册，已有账号仍可登录；默认沿用原配置的 `registration_enabled=true`，不需要公开注册的站点请关闭。注册仅授予普通用户角色，默认会员和首次赠送积分均使用后台配置；密码 12–128 个字符。邮箱暂不验证，邮件自助找回仍未开放。注册按 IP 默认每小时最多 5 次请求，可在安全策略中调整。
- **总览**：修复会员统计只分组套餐代码、却按会员等级排序的 PostgreSQL 错误；趋势接口单独失败时仍显示总览指标。
- **印花提取**：新增独立操作 `ai.extract_print`，迁移自动建立操作与 18 积分初始价格。“功能定价”可单独改价或关闭，不改动已有工具价格。使用当前后台 Sub2API 图片配置，通过正常异步任务、报价、扣费和退款流程处理。
- **旧版核实**：旧同步接口 `workflow.py` 的 `faithful-redraw` 包含去产品、去褶皱、校正透视并生成纯绿/洋红背景的印花提取提示词。现将此行为移到独立提取工具，之后沿用纯色转 Alpha 处理，保留白墨与黑墨；若上游直接输出透明图则保留其透明通道。无法安全去底或没有有效印花的结果会失败并退款，不会假装已输出透明文件。旧同步 API 的兼容路由保持原状，生产站使用 `/api/v1` 异步工具。
- **高清重绘**：聚焦去模糊、压缩噪点与锯齿，保留原图主体、背景、构图和透视，不提取产品印花。AI 仍可能改变细节，文字、商标和配色需检查后用于生产。输出分辨率由现有模型支持的尺寸决定，不承诺原生 4K；可按需要继续使用放大工具。
- **编辑器**：顶部工具栏、右侧设置、中央双栏原图/结果；所有已有图片操作保持左右对照，新建图显示单栏。悬停两侧任意一张图可按同一相对位置同步放大 2/3/4 倍；支持触屏按住与键盘方向键。提取操作会改变图案构图，因此该对照不是自动像素配准。涂抹修复时暂停放大，避免影响画笔。
- **品牌**：登录、用户导航、管理后台与浏览器图标使用新 SVG Logo，登录和首页接入 POD 植物主题原创矢量配图。资源在 `frontend/public/brand-symbol.svg`、`frontend/public/studio-collection.svg`。这些为代码制作的矢量资源；当前开发环境没有 `OPENAI_API_KEY`，尚未生成 AI 位图配图。配图生成稿和命令见 `docs/website-artwork.md`。

## 修复内容

- 修正积分流水与任务关联的写入顺序。原来扣费流水尚未 INSERT，任务就先 UPDATE 关联流水，在 PostgreSQL 外键检查下失败，并被错误地提示为“任务状态已变化”。现在先写入流水，再建立关联；全过程仍处于同一事务内，失败整体回滚。
- 扣费、退款、管理员调账共用修正后的流水写入逻辑。数据库异常返回真实的保存失败提示和请求编号，服务端记录 SQLSTATE 与约束名称。
- 同一报价重试使用相同幂等标识，网络异常保留报价与输入；任务结束后读取真实余额。
- 结果发布稍晚于任务完成时继续获取结果；预览链接自动续期，支持手动重新载入。
- 重做工作台和编辑器布局：参数独立滚动、提交区固定可见、画布展开、原图对比、结果继续编辑、移动端布局。
- 局部修复/文字修正支持画笔涂抹、撤销与清空，导出与原图同尺寸的透明 PNG 遮罩。更换来源图时清除旧遮罩。

## 服务器更新

先提交并推送本地改动，等待 GitHub 的 **Quality gates** 和 **Publish production image** 成功。尚未发布新镜像时，仅在服务器拉取 `latest` 不会得到本次修复。

在服务器当前项目目录执行以下命令。保持原有 `.env` 与密钥；建议把 `IMAGE_TAG` 设为这次发布的 `sha-完整40位提交ID`，以便确认版本和回滚。

```bash
# 把下面的示例标签替换为实际发布的镜像标签
export IMAGE_TAG=sha-实际完整40位提交ID
docker compose -f docker-compose.server.yml pull web worker scheduler migrate
docker compose -f docker-compose.server.yml run --rm migrate
docker compose -f docker-compose.server.yml up -d web worker scheduler
docker compose -f docker-compose.server.yml ps
```

确认版本后，将同一个 `IMAGE_TAG` 写回服务器 `.env`，避免以后在新终端重建容器时退回旧标签。

更新后浏览器强制刷新一次。分别验证一项本地处理（如颜色处理）与一项 AI 操作，检查报价、积分、任务完成、结果预览与下载。实际 AI 调用还依赖服务器的 Sub2API/R2 配置与服务可用性。

如仍报错，保留页面的请求编号，并在服务器查看对应日志：

```bash
docker compose -f docker-compose.server.yml logs --since=10m web worker scheduler
```

`IMAGE_JOB_SAVE_FAILED` 是数据库保存失败，日志包含约束名称；上游执行失败会显示具体原因，并通过正常失败流程退款。不要清空数据库或更换应用加密密钥来处理此问题。
