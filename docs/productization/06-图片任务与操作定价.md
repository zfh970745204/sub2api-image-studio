# 06 图片任务与操作定价

## 1. 功能范围

- 管理员配置每种操作的启用状态、基础积分、参数加价和会员折扣策略。
- 用户执行前获得准确报价；提交时按计价快照扣费。
- 图片处理进入异步队列，页面可查看排队、运行、成功、失败和退款状态。
- 支持安全重试、超时处理、取消排队任务和失败补偿。
- 每项操作配置资源限制、超时和 Worker 队列。

## 2. 操作目录与建议初始价

以下仅为首发建议，最终价格必须由管理员后台配置：

| 操作代码 | 页面功能 | 执行引擎 | 建议积分 |
|---|---|---|---:|
| `ai.generate` | AI 生成图案 | Sub2API | 20 |
| `ai.redraw` | 高清重绘各模式 | Sub2API | 18 |
| `ai.repair` | 局部修复 | Sub2API | 15 |
| `ai.text_fix` | 文字修正 | Sub2API | 15 |
| `ai.variant` | 生成变体 | Sub2API | 18 |
| `cutout.smart` | 智能抠图 | 色键代码/U2Net | 2 |
| `upscale.2x` | 2x 放大 | Lanczos | 2 |
| `upscale.4x` | 4x 放大 | Lanczos | 6 |
| `color.effect` | 灰度/黑白/反色/单色 | OpenCV | 1 |
| `vectorize.svg` | 矢量化 | OpenCV | 3 |

后台应显示执行引擎和成本来源，避免把纯代码操作误标为外部 AI。

## 3. 权限与规则

| 行为 | 用户 | `pricing.read` | `pricing.manage` | `tasks.manage` |
|---|---:|---:|---:|---:|
| 查看可用操作与本人报价 | 是 | 是 | 是 | 是 |
| 创建本人任务 | `tasks.create` | 否 | 可选 | 可选 |
| 修改价格/启停操作 | 否 | 否 | 是 | 否 |
| 查看/重试任意任务 | 否 | 否 | 否 | 是 |

规则：

- 报价有效期建议 5 分钟，并返回 `quote_id` 和定价版本。
- 最终价格为 `max(0, ceil(base_points * membership_discount_bps / 10000) + parameter_surcharge)`。
- 任务创建后价格不可修改；管理员新价格只影响新报价。
- 排队任务可取消并全额退款；运行中任务默认不可取消，避免已产生上游成本。
- 外部 AI 返回 429/5xx 可自动重试，4xx 参数/鉴权错误直接失败退款。

## 5. 状态机

```text
queued -> running -> succeeded
queued -> cancelled + refund_status=refunded
queued -> running -> failed + refund_status=refunded
running -> retry_wait -> queued
running -> timed_out + refund_status=refunded
```

任务状态与退款状态分别保存，从而保留失败、超时或取消原因。只有领域服务能迁移状态。Worker 结果写入采用比较更新，例如只允许同一尝试的 `running -> succeeded`，避免超时补偿后迟到结果覆盖最终状态。内部重试保留原扣费；已进入终态并退款的任务不能原地重跑，必须重新报价创建新任务。

## 7. 验收标准

- 前端展示的积分价格与实际扣费完全一致。
- 改价不会影响已报价且未过期的请求，也不会改变历史任务。
- 同一请求重试只创建一个任务并扣一次积分。
- 所有最终失败任务自动退款，所有成功任务保留消费流水。
- Web/Worker 重启后任务能继续或进入可补偿状态。
