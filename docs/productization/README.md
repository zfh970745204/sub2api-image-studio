# Sub2Image 生产化整改文档

本目录把当前单机图片工作台升级为可公开上线的多用户 SaaS。文档按研发依赖顺序排列，实施时不得跳过基础架构、权限和积分账务，直接开发管理后台页面。

## 目标版本

- 用户可注册、登录、管理自己的图片与任务。
- 角色权限（RBAC）与会员等级彼此独立。
- 每项图片操作按可配置规则扣除积分，失败自动退款且不得重复扣费。
- 原图、结果图和遮罩存储到 Cloudflare R2 私有桶。
- 管理员可在后台管理用户、会员、积分、任务、价格、系统配置和密钥。
- Sub2API、R2、邮件等业务密钥由管理员在后台维护，浏览器永远看不到密钥明文。
- 系统具备审计、限流、监控、备份、迁移和回滚能力。

## 首发范围

首发包含账户、RBAC、会员、积分、操作定价、异步任务、R2、管理员后台、用户端改版和生产运维。不在首发中接入在线支付、发票、团队空间、开放 API 和多租户组织；相关表结构保留扩展空间，但不提前实现无业务价值的复杂度。

## 核心约束

1. 用户只能访问自己拥有的资产和任务，管理员越权查看也必须留下审计记录。
2. 积分流水不可修改或删除，只能通过反向流水冲正。
3. 每个任务保存计价快照，管理员改价不得影响已创建任务。
4. R2 桶保持私有，禁止把永久公开地址保存到数据库或返回前端。
5. 密钥写入数据库前必须加密，读取接口只返回“已配置”和掩码。
6. 数据库连接、Redis 连接和配置加密根密钥属于启动根信任，不能存进同一个数据库；其余业务密钥均由管理员后台配置。
